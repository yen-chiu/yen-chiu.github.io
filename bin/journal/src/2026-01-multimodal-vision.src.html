多模态视觉的机制、边界与前沿：
从图像表示到统一 token 空间的综述

Mechanisms, Limits and Frontiers of Multimodal Vision:
A Survey from Image Representation to a Unified Token Space

Wendell

独立研究者 · yenchiu.com

收稿日期：2026-11-06　　接受日期：2026-11-06

摘要　以大型语言模型为核心的系统在近三年内普遍获得了读图、理解图与按图编辑的能力，这一变化常被简化为"模型长出了眼睛"。本文认为该表述掩盖了真实机制，并对这一领域的进展做了一次系统性梳理。综述沿四条线索展开：其一，回顾视觉表征从卷积网络到视觉 Transformer 的演进，说明图像如何被切分为离散 token；其二，梳理视觉—语言对齐路线，以 CLIP 的双塔对比学习为关键基础设施，讨论对齐空间的语义性质及其代价；其三，归纳多模态大模型的三种连接范式——投影层、重采样交叉注意力与原生融合，并论证"看图"在统一 token 空间中被还原为"读上下文"的机制；其四，考察生成与编辑任务对视觉理解的依赖关系，指出编辑能力的天花板由理解而非生成决定。在此基础上，本文结合公开评测中反复出现的失败模式与一个经典案例，区分"能看"与"看懂"，指出空间关系、实例计数、文字渲染与接触关系仍是系统性薄弱环节，并给出将视觉视为接口而非感官的判断。

关键词　多模态大模型；视觉—语言对齐；图像 token 化；对比学习；图像编辑；能力边界

Abstract　Systems built around large language models have, within roughly three years, acquired the ability to read, reason over and edit images. This change is often described as models "growing eyes", a phrasing that obscures the actual mechanism. This survey reviews the field along four lines: the evolution of visual representations from convolutional networks to vision transformers and the resulting tokenization of images; the vision–language alignment route anchored by CLIP's dual-encoder contrastive training, together with the semantic properties and costs of the aligned space; three connection paradigms of multimodal LLMs—projection layers, resampler-based cross-attention and native early fusion—through which "seeing" is reduced to "reading context" in a unified token sequence; and the dependence of image generation and editing on visual understanding, where the ceiling of editing is set by understanding rather than by generation. Drawing on failure modes repeatedly reported in public benchmarks and on one classic case, the paper distinguishes "being able to see" from "seeing correctly", identifies spatial relations, instance counting, text rendering and contact relations as systematic weaknesses, and concludes that for large models vision is an interface rather than a sense.

Keywords　multimodal large language models; vision–language alignment; image tokenization; contrastive learning; image editing; capability boundary

1　引言

二〇二〇年之前，计算机视觉与自然语言处理基本是两个互不相通的技术栈：前者以卷积网络加标签监督为主，后者以序列建模为主，二者的接口需要人工设计，例如用固定的标签集合把图像压成一个类别向量，再喂给下游的语言任务。这种接口的带宽极低——一张图最后只剩下一个类别名。

变化发生在两条技术路线汇合之后。一条路线把图像切成小块并当作序列处理，使图像与文本在"序列"这一形式上取得了同构；另一条路线用海量图文对做对比学习，把图像和文本映射到同一个语义空间，使"狗"这个词与一张狗的照片在向量上彼此靠近。两者叠加之后，语言模型不再需要专门的视觉模块，只要把图像 token 与文本 token 拼进同一条上下文，视觉理解就退化成了它本来就擅长的任务。本文把这一过程称为"从切块到同框"。

本文试图回答四个问题：图像是如何变成语言模型可读的 token 的；"对齐"在这条链路上扮演什么角色；为什么生成与编辑模型同样需要视觉理解；以及，既然系统能够正确描述一张图，为什么仍会在计数、空间关系与文字识别上反复出错。文章的组织如下：第 2 节回顾视觉表征的演进；第 3 节讨论视觉—语言对齐；第 4 节归纳多模态连接范式；第 5 节分析生成与编辑对理解的依赖；第 6 节综述评测与典型失败模式；第 7 节从 token 预算与几何约束两个角度剖析边界；第 8 节讨论开放问题；第 9 节总结。

2　视觉表征的演进：从卷积到切块

2.1　卷积网络时代

以 AlexNet [1] 为起点的卷积网络奠定了近十年的视觉表征基础，其核心假设是局部感受野与平移等变性：同一组卷积核在图像上滑动，天然编码了局部纹理与边缘。残差连接 [2] 解决了深层网络的退化问题，使网络深度从十几层推进到上百层。这一范式的输出是一个全局池化后的定长向量，主要用于分类、检测与分割等任务，其语义是"类别层面"的，缺乏可供语言模型直接消费的细粒度结构。

2.2　视觉 Transformer 与图像切块

Vision Transformer（ViT）[4] 把图像直接视作序列：将 H×W 的图像切成 P×P 的不重叠小块，每块展平成向量后经线性映射得到 token，并加上位置编码。第 i 个视觉 token 可写作

zi = E · xpi + epos(1)

其中 xpi 为第 i 个展平后的图像块，E 为投影矩阵，epos 为位置编码。公式 (1) 的意义远不止工程实现：它把"图像"改写成了"序列"，而序列正是语言模型的原生输入格式。以自注意力 [3] 为主干的 ViT 在大规模数据上超越卷积网络的实验结果，进一步说明局部性并非视觉理解的必要条件，数据规模与全局注意力可以替代手工设计的归纳偏置。

需要指出的是，切块同时带来了一个不可逆的信息损失。一张 1024×1024 的图像在 P=16 时被压缩为 4096 个 token；若下游语言模型每张图只能接收数百个 token，则视觉编码器必须再做一次降采样或重采样。物理上的细节在第一次切块时就已经丢掉了一部分，这一点在第 7 节讨论能力边界时会再次出现。

2.3　自监督预训练与目标函数的转变

与架构变化同样重要的，是训练目标的转变。早期视觉模型依赖人工标注的类别标签，监督信号的信息量被标签空间的大小严格限制。掩码自编码类方法 [22]（随机遮挡图像块，要求模型依据上下文重建）把监督信号换成了图像自身，使模型可以在无标注数据上学习纹理与结构；自蒸馏类方法 [23]（用教师网络指导学生网络处理同一图像的不同视图）则进一步把"不变性"作为学习目标，让表示对裁剪、缩放、色彩扰动保持稳定。

这一转变的后果常被低估：一旦目标函数从"预测标签"变为"重建内容"或"保持一致"，模型学到的表示就不再被类别集合束缚，而对齐训练所需要的正是这种开放的、稠密的视觉表示。换句话说，对比学习之所以能成功，前提是视觉编码器已经能够输出与具体任务无关的通用特征；如果还停留在分类范式，整图嵌入里几乎没有可用于细粒度语义匹配的信息。

三条线因此是叠加关系而非替代关系：架构提供了可序列化的表示单位，预训练目标提供了通用特征，对齐训练提供了跨模态的语义落点。缺少任何一环，多模态能力都无从谈起。

3　视觉—语言对齐：CLIP 及其后续

3.1　双塔对比学习

CLIP [5] 的做法是训练两个独立的编码器，分别把图像与文本映射到同一维度的向量空间，并在一个批次内用对比目标拉近匹配的图文对、推开不匹配的对。对批次内第 i 个样本，其对称形式的损失为

L = − (1/N) Σi log [ exp(sim(zi, ti)/τ) / Σj exp(sim(zi, tj)/τ) ](2)

其中 zi 与 ti 分别为图像与文本的归一化嵌入，τ 为可学习的温度系数。公式 (2) 的关键在于"对比"这一形式本身：它不要求模型生成描述，只要求它在四亿量级的图文对中判断哪段文字对应哪张图。这种弱监督信号的规模优势，使得视觉表征第一次具备了开放词表的语义覆盖能力——不再局限于固定的类别集合。

3.2　对齐空间的性质与代价

对齐空间有一个常被忽视的性质：它本质上是"词袋式"的。因为训练目标只关心整张图与整段文本的相似度，模型并不需要理解句子的语法结构，也不需要知道物体的相对位置。这带来两个后果。其一，空间关系与计数类查询天然处于劣势，因为"猫在桌上"与"桌在猫上"在整句嵌入层面差异很小；其二，模型对视觉中的文字内容异常敏感，因为它本身就是被文字监督训练出来的。

后一点在公开研究中被反复观察到：在图像上叠加一个与物体无关的文字标签，可以系统性地改变模型的分类输出。这一现象通常被称为排版攻击（typographic attack）[17]，其成因正是图文对齐训练把"视觉上的字形"与"语义上的词"绑定得过于紧密。本文第 6 节会把它作为一个经典案例展开。

后续工作沿两个方向改进：一是扩大规模与清洗数据（如 ALIGN [6] 之于噪声图文对），二是改进目标函数（如 SigLIP [7] 用 sigmoid 替代 softmax，降低对批次内负样本的依赖）。但"整图—整句对齐"的基本框架没有改变，上述代价也就一直存在。

3.3　对齐的评估与零样本能力

对齐质量通常用零样本迁移能力来间接衡量：在训练时从未见过的分类数据集上，把数据集的类别名直接写成文本提示，与图像嵌入做相似度匹配，取最接近的一项作为预测。这一评测方式的意义在于，它检验的不是模型记住了哪些类别，而是视觉嵌入空间能否被自然语言任意索引。当零样本精度接近有监督训练的模型时，说明对齐空间已经足够稠密、足够语义化。

然而这种评测也掩盖了问题。零样本分类只要求"在最像的那几个词里挑一个"，对细粒度差异不敏感；它无法检验模型是否理解物体的相对位置、数量或状态。因此在很长一段时间里，文献中报告的零样本分数持续上升，而实际使用中模型却在简单计数任务上频繁出错——评测指标与真实能力之间出现了系统性的偏差，这一点在第 6 节还会讨论。

4　连接范式：图像如何进入语言模型

有了对齐良好的视觉编码器，下一个问题是：如何把视觉 token 接到语言模型上。文献中大致形成三种范式，它们的差别在于"在哪里合并"与"合并多少"。

4.1　投影层范式

最简洁的做法是在视觉编码器与语言模型之间插入一个轻量投影层（通常是一到两层 MLP），把视觉 token 直接映射到语言模型的词嵌入空间，然后与文本 token 拼接成一条序列送入语言模型。LLaVA [11] 是这一范式的代表：视觉编码器与语言模型都冻结，只训练投影层，即可获得可用的图文对话能力。其代价是视觉 token 数量庞大——一张图往往对应数百个 token，在长上下文场景中开销显著。

4.2　重采样与交叉注意力

第二类范式引入一个可学习的"瓶颈"，用少量查询向量通过交叉注意力从视觉特征中抽取固定数量的表示。Flamingo [8] 的 Perceiver Resampler 与 BLIP-2 [9] 的 Q-Former 都属于此类：无论输入图像分辨率如何，输出到语言模型的 token 数都是固定的（例如 32 或 64 个）。这解决了 token 预算问题，但也引入了一个新的信息瓶颈——重采样器必须自行决定哪些信息值得保留，而这一取舍是在训练中隐式学到的，不可解释、也不可控。

4.3　原生融合与统一 token 空间

在走向原生融合之前，BLIP [10] 已尝试用一个统一的编码器—解码器结构同时承担图文检索、描述生成与视觉问答，是"统一"目标上较早的一次尝试，但它的视觉编码器与语言侧仍然分离。

第三类范式不再区分"视觉侧"与"语言侧"，而是在预训练阶段就把图像 token 与文本 token 混在一起训练，让模型从零学习跨模态的联合表示。这类模型在指令跟随与跨模态推理上通常表现更好，代价是训练成本高、且失去模块化替换的便利。

三种范式殊途同归：无论视觉 token 是几百个还是几十个，最终都是与文本 token 排在同一条自回归序列里。而一旦进入同一条序列，"看图"这件事对模型而言就变成了"在上下文中读取前面那些向量"。这正是本文标题中"同框"的含义——模型并没有增加一种感官，它只是多了一种输入格式。理解这一点，后面关于能力边界的讨论才讲得通。

5　生成与编辑：为什么"画"也需要"看"

5.1　文生图的基本框架

扩散模型 [12] 把生成建模为逐步去噪的过程，其训练目标可写为

L = Ex,ε,t ‖ ε − εθ(xt, t, c) ‖²(3)

式 (3) 中，c 为条件（通常是文本嵌入），xt 为第 t 步加噪后的样本。潜空间扩散 [13] 把去噪过程放在压缩后的潜空间中进行；DALL·E 2 [14] 则先在 CLIP 潜空间中生成图像嵌入、再解码为像素，属于层次化的生成路线，大幅降低了计算成本，也使高分辨率生成变得可行。值得注意的是，这一框架对"条件"的形式没有强约束：任何可编码为向量的东西都可以作为条件，这为后来的图像条件、结构条件、参考图条件留下了扩展空间。

5.2　编辑任务重新引入理解

文生图只需要把文字变成图，模型并不需要真的"理解"图上有什么。但图像编辑不同，它要求模型同时做三件事：读懂原图的内容与结构、听懂指令指向的对象与操作、并在生成后保证未改动的部分保持一致。这是一个"图像 + 文本 → 图像"的问题，理解能力第一次成为生成能力的必要条件。

实践中发展出两条路线。一是把编辑拆成"理解—定位—重绘"三段，理解与定位交给多模态模型，重绘交给扩散模型，中间用蒙版传递位置信息；二是让模型直接学习配对数据，如 InstructPix2Pix [15] 一类工作以大量"编辑前后"图像对训练条件生成模型。两条路线对理解能力的要求是一致的：定位错了，重绘再精细也是错的。

结构条件控制 [16]（如从边缘、深度、姿态图中提取几何约束并注入去噪网络）进一步说明，编辑质量的瓶颈往往不在生成端，而在"能否准确提取并保持结构"。当结构信息提取不准时，模型会用语义先验去填补，结果就是生成出"看起来合理但实际错位"的内容——这一点在第 6 节的失败模式中会具体展开。

5.3　分层编辑：为什么一次改完总会崩

如图 2 与表 1 所示，三种范式的差别集中在瓶颈位置；实际使用中很快出现一条经验规律：一条指令同时改动越多、改动范围越大，结果越容易崩坏。原因是编辑任务里混着两个性质完全不同的子问题——影调与风格是全局、低频、可容忍误差的；人物结构、物体边界与接触关系是局部、高频、不容忍误差的。前者的评价标准是"像不像那个味道"，后者是"对不对"。

把两者放进同一次生成，模型会用同一套权衡去处理，结果往往是风格改得漂亮、结构却先塌了。更稳的做法是分层：先用低强度生成完成全局影调与质感，再用蒙版把结构敏感区域（手、脸、物体交界）单独保护或单独重绘。这一做法在工程上代价更高，但它把"理解"与"生成"的误差分开了，出错时也能定位到具体环节。近期流行的"参考图 + 局部重绘 + 分层合成"流水线，本质就是对这一分工的工程化表达。

6　评测与典型失败模式

6.1　评测基准

多模态能力的评测已从早期的图文检索扩展到综合问答、细粒度感知与专业知识推理。综合型基准如 MME [18] 通常按感知与认知两个维度切分，覆盖存在性、计数、位置、颜色、文字识别等子任务；学科型基准则如 MMMU [19] 用大学水平的考题检验跨模态推理。这些基准的共同局限是：它们大多以选择题或短答案形式呈现，对"描述是否精确"的判别力有限，且题目本身可能被训练数据污染。

6.2　一个经典案例：排版攻击

在多模态视觉的研究中，被引用得最多的异常现象之一是所谓排版攻击。实验设置极为简单：取一张可以正确分类的图像，在画面上叠加一个手写风格的文字标签，标签内容与图像无关，再让模型重新分类（实验设置见图 4）。结果是分类结果被系统性地改变——模型会倾向于输出标签上写的那个类别，而忽略画面本身。

这一现象的价值不在于它"错得多离谱"，而在于它暴露了对齐训练的机理。由于模型是在海量图文对上学习"整图—整句"的相似度，其中相当一部分监督信号来自网页中的文字，视觉字形与语义词在被训练过程中被绑定得过紧。当画面中出现清晰可读的文字时，文字的语义权重会压过物体的视觉证据。这解释了一个看似矛盾的现象：模型既能识图，又会被图中的字带偏。它也提示了第 3 节所讨论的对齐空间代价——对比目标不约束结构，只约束整体相似度。

6.3　基准的可信度问题

评测分数与真实体验之间的落差，近年逐渐成为公开讨论的话题，其来源大致有三类。其一，数据污染：大规模预训练语料的边界难以界定，基准题目或其近似变体可能已经出现在训练数据中，导致分数虚高。其二，指标错位：多项选择题只要求模型在给定选项中挑一个，即便模型并不真正理解图像，也可能凭借语言先验排除干扰项获得高分。其三，偏置：题目构成偏向某类图像来源或某类表述方式，模型在分布外的真实使用场景中表现明显下降。

更根本的问题是，人类对"看懂一张图"的判断本身是模糊的：我们通常无法量化自己究竟调用了哪些线索。这使得构建与人类感知一致的评测，比构建更难的任务更难。一个可行的折中是把评测拆细：不报告一个总分，而是分别报告感知、定位、关系与推理四个环节，使失败可以被归因。这也是本文第 7 节剖析边界时所依赖的方法论前提。

7　能力边界的两个来源

7.1　token 预算与分辨率的矛盾

视觉 token 的数量与图像细节成正比，而语言模型的上下文预算与推理成本也随 token 数线性增长。这两条曲线方向相反，工程上的折中必然造成信息损失。设原图边长 H、切块大小 P、重采样后保留 n 个 token，则压缩比为

ρ = n / (H/P)²(4)

当 ρ 远小于 1 时，每个保留的 token 必须承担多个图像块的信息，细节在进入语言模型之前就已经不可恢复。这解释了为什么模型能说对"图里有一只狗"，却说错"图里有几只狗"（图 5）——实例计数需要保留每个实例的独立表征，而重采样恰恰在做合并。

7.2　统计特征与几何约束

第二个来源更根本。视觉编码器输出的是对图像块内容的统计性描述，它擅长回答"这里有什么"，不擅长回答"它们之间精确的空间关系如何"。几何关系需要显式的坐标与约束，而注意力机制本身并不保证局部性，位置编码也只提供相对位置的弱提示。当语言先验（例如"杯子通常放在桌上"）与画面中的实际情况冲突时，模型往往选择相信先验（图 6）。这也是接触关系、遮挡关系错误频发的根源。

需要强调的是，这两点都不是"模型不够大"能解决的问题，它们属于表示形式本身的约束：只要视觉信息必须被压缩成有限个与文本同构的 token，就必然存在一类无法被精确表达的关系。

8　开放问题

（1）原生视觉推理。以 GPT-4 系列 [20] 为代表，当前的主流做法是"先编码、后推理"，推理发生在符号层面。若能在连续表示上直接进行多步推理，而不经过离散 token 的瓶颈，可能突破第 7 节所述的约束。这条路线在计算上仍有明显障碍。

（2）动态与视频。图像是静态的，视频引入了时间维度。当前多数系统的处理方式仍是抽帧后按图像处理，这既丢失了运动信息，也放大了 token 预算矛盾。如何表示"变化"而非"状态"，仍是未解问题。

（3）评测的可解释性。现有基准给出的是聚合分数，难以定位失败发生在感知、对齐还是推理环节。构建能够分解误差来源的评测方法，比继续堆高分数更有价值。

（4）编辑中的身份保持。在图像编辑任务中，保持人物身份、服装、姿态的一致性是长期难点。这本质上是"理解"与"生成"之间的对齐问题，尚无系统性解法。

（5）安全与可控。视觉输入绕过了纯文本系统的许多过滤手段：一篇被截图传播的违规文本、一张嵌入了提示词的图像，都可以进入模型上下文。当前的对齐训练（如基于人类反馈的强化学习 [21]）主要针对文本，视觉侧的对齐数据与方法都远不成熟。随着系统接入摄像头与终端设备，这一缺口的重要性会迅速上升。

（6）成本与可及性。视觉 token 的引入使推理成本上升一个量级，而高质量多模态模型的训练开销远高于同等规模的纯文本模型。如何在保持能力的前提下降低单位成本，决定了这类系统能否部署在端侧。

9　结论

本文梳理了多模态视觉从图像切块、图文对齐到统一 token 空间的演进路径，论证了三件事。第一，视觉能力的出现并非新增感官，而是图像被翻译为语言模型既有表示空间的结果；决定能力上限的，是这次翻译的粒度与保真度。第二，生成与编辑任务同样依赖理解，编辑能力的天花板由理解而非生成决定。第三，模型在计数、空间关系、文字与接触关系上的系统性失败，来源是 token 预算与几何约束这两个表示层面的限制，而非单纯的规模不足。

因此，更准确的表述是：对大型模型而言，视觉不是一种感官，而是一个接口。它不"看"世界，它读世界被翻译成的那个版本。理解这一点，既有助于解释现有系统的失败，也提示了下一步值得投入的方向——不是把图像塞进更多的 token，而是重新思考图像在被翻译之前应该保留什么。
