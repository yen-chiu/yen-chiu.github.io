# Gallery / 光影档案

Static Astro gallery. R2 is object storage, not a relational database. Git-versioned metadata in src/data/photos.ts is the initial catalogue. Upload only exported, GPS-stripped WebP/JPEG derivatives to your own public R2 custom domain, then add their thumbnail and preview HTTPS URLs and dimensions to the catalogue. Keep RAW and originals in a private bucket. Set lifecycle and CORS as appropriate; no credentials in client code. No bucket or external database has been provisioned.

Design references: Frud's Blog (https://www.aibrium.cn/), astro-gallery (https://github.com/SlashGordon/astro-gallery), PicImpact (https://github.com/besscroft/PicImpact), PhotoSwipe (https://photoswipe.com/). Original implementation uses native dialog, no copied code or photographs. Current gallery is empty until authorized photographs are supplied. Future work: upload pipeline, srcset derivatives, albums with dedicated routes, optional D1 if authenticated admin is needed.

## Gallery Studio CLI
Copy scripts/gallery-manifest.example.json to a private local manifest outside the repository. Install dependencies and AWS CLI v2. Run node scripts/gallery-studio.mjs /path/to/manifest.json for local derivatives; review .gallery-studio-output before publishing. Set R2_ACCOUNT_ID, R2_PUBLIC_BUCKET=yenchiu-gallery, R2_PUBLIC_URL=https://gallery-cdn.yenchiu.com, R2_PUBLIC_ACCESS_KEY_ID, R2_PUBLIC_SECRET_ACCESS_KEY. Run the same command with --publish to upload and update src/data/gallery-photos.json. Optional --backup-originals additionally requires R2_PRIVATE_BUCKET=yenchiu-gallery-originals and separate R2_PRIVATE_ACCESS_KEY_ID and R2_PRIVATE_SECRET_ACCESS_KEY. Do not commit credentials, source photos, local manifests or output. Sharp strips metadata from derivatives by default; camera and date are manually supplied. RAW decoding is not supported by this pipeline; export JPEG first. Review catalogue before committing. Public r2.dev can be disabled after custom-domain access is tested. No live upload has been tested.
