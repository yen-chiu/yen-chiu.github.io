# 异次元通讯 · 次元复苏 — 网页移植版

把 Android 版《异次元通讯·次元复苏》（Flutter + Dart AOT）的**剧情与美术**移植为纯静态网页，
零依赖、零构建：原生 HTML / CSS / JS，双击 `index.html` 或放到任意静态服务器即可运行。

## 目录

```
miko/
├── index.html          # 单页应用：章节选择（第一章 → 番外：帮 Miko 烤蛋糕 → 第二章 → 番外：和 Miko、小艾姐打 UNO → 第三章 …） / 聊天 / 词典 / 图鉴 / 动态 / 设置
├── style.css
├── app.js              # 剧情引擎（块跳转 + 兄弟块跳过）、打字动画、收藏、存档
├── data/
│   ├── story.json      # 8 章全部剧情（14,401 行 → 结构化 rows/blocks/choices）
│   └── meta.json       # 词典 / 图鉴 / 动态 / 语音 / 天数 / 释义
└── assets/             # chapter / dictionary / icon / images / music / photo（99 个文件）
```

数据由 `00_工具/web_build.py` 从原始 CSV 与素材编译而来，重新生成：

```powershell
cd <改动工作区>
python -X utf8 00_工具\web_build.py
```

## 已实现

- **剧情完整**：8 章、14,401 行、153,233 字，1,278 个二选一选择点全部可用；
  按原作「跳转表」语义还原——选项进入目标块，块内显式跳转优先，块结束时跳过同组兄弟块回到主线。
- **聊天体验**：左/中/右三种气泡、`对方已上线/下线` 系统条、Day 分隔、语音消息（可播放）、
  动态图文卡（点击放大）、BE 提示、等待卡（默认真实分钟数）。
- **私聊式头部**：顶部固定「对象名 + 状态」——对方打字时显示「对方正在输入…」，
  下线后显示「上次在线 N 分钟前 / N 小时前 / N 天前」（由剧本里的上线/下线系统条驱动）。
- **右上角菜单**：自动播放（逐条推进、选项自动选第一个）、立即显示（跳过打字与等待）、
  跳到某天（按 `DayN` 分节跳转）、词典/图鉴/动态、后日谈、设置、重开本章。
- **动态互动**：每条动态可点赞、可评论（存本机，随存档导出）；动态按故事顺序排（第一→六章，番外最后），
  点聊天里的角色头像进入对应空间。
- **后日谈**：结局之后仍可继续说话；预留 `window.MIKO_AI = async (history, text) => "..."` 接口，
  接上任意模型即可让「她」接着回话（未接入时只记录本地）。
- **收藏系统**：词典 109 条（30 条有释义，来自静态提取）、图鉴 43 张、动态 34 条，
  剧情中触发即解锁，存 `localStorage`。
- **角色头像**：Miko / Iris / Lily / 未知用户 各自有头像（默认 `头像2 / 头像3 / Lily / 未知用户`）；
  设置里点右侧箭头弹出**竖排头像列**（10 张素材 + 「字母」），选中即生效。
- **我的形象**：按 QQ 号从 qlogo 取头像（原重置版的做法），或上传本地图片裁成方形存本机；不设置则不显示。
- **主题头像**：她在剧情里发照片（动态）时，头像同步换成与该照片主题对应的一张（表在 `00_工具/web_build.py` 的 `AVATAR_THEME`）：
  第一章 星空自拍 → `头像2`、第二章 咖啡店 → `头像3`、第三章 沙发/遮脸 → `头像8`、第四章 校服 → `头像2`、
  第五章 → `头像6`、第六章 → `头像7`、番外一 → `头像5`（草帽/夏天）、番外二 → `头像4`。
  还没发过照片时用 `头像-黑白`（原版 `chat_left_avatar.png` 去掉蓝色描边后裁圆，奶白底 + 黑色无脸身影）——就是原作第一章那个「看不清脸」的头像。
- **头像三态**：未知 = 问号（`未知用户.webp`）→ 知道名字 = 黑底字母（`M`/`I`/`L`）→ 她发过图（动态/图鉴）= 人物立绘。
  切换点都在**主线**，不依赖番外：Miko 第一章 448 行（「我这里能看见星星，你呢」那条动态）、Iris 第三章 1380 行、Lily 第六章 968 行（她第一次开口）。
- **头像随剧情解锁**（还原原作）：没认识的角色一律显示问号头像（素材里那张 `未知用户.webp`），
  走到「自报姓名」那一行才换成真头像并写进存档 —— 第一章 446 行「我叫Miko，谢谢你」、
  第三章 697 行「我叫Iris」、第六章 970 行「我是Lily」。设置里可关闭。
- **节奏**：以原版实测时长为准——前三章 + 两番外共 2,882 句逐字命中取原版 `busyWaitTime`，
  其余用拟合模型（`523 + 175 × 字数` ms）；慢/中/快 = 1.35×/1×/0.6×。
- **等待**：剧本里的分钟数**默认按真实时长**（1×，和剧情里一致）折算，「预计5分钟」就是 5 分钟；可切 10× / 60× / 不等待，等待卡上有「跳过等待」。
- **存档**：进度、解锁记录、设置打包成一个 JSON，可导出下载、在别的设备导入，换浏览器不丢。
- **设置**：打字速度（慢/中/快）、等待倍速（真实 / 10× / 60× / 不等待）、背景音乐、音效/语音、自动解锁全部收藏、
  头像随剧情解锁开关、角色头像与「我的形象」、存档导出/导入、清空进度；
  底部「本页与原版的差别」对照表默认折叠，点开看 15 项逐条对比。

## 已知限制

- **词典释义**：原作的 111 条释文以 UTF-16 硬编码在 `libapp.so` 的 Dart 快照里，静态只能恢复 30 条，
  且两端或夹着错位扫描噪声（已用「正文用字集合」做窗口裁剪，仍可能残留 1–3 字）；
  其余词条显示为「释义数据未收录」。
- **剧情内容**：发布包本身有 2 处列错位（第六章第 106 行、第四章第 760 行），本数据已修正；
  原作语义异常（词典编号 2–25/27/38 空洞、39 与 44 编号重复）保持原样，不做猜测性填补。
- **美术与音乐版权归原作者所有**，本移植仅作个人研究与怀旧用途，未商用、未改动素材内容。

## 素材说明

图片为原作 `assets/photo/` 原图（WebP），章节封面在 `assets/chapter/`，
BGM 为 `bgm.ogg`（原曲 3.3 MB 的完整版 `oldBgm.ogg` 也保留了，未默认播放）。

- **图鉴**：按章分组（`第一章 5/6`），三列缩略图；未解锁是黑封面 + 挂锁，点击解锁项看大图。
- **动态**：QQ 空间式个人页——封面、头像、昵称、签名与标签，下面按时间（章节）列动态；
  聊天里点对方头像即可进入 `#/feed/<角色>`。
- **我的形象**：设置里填 QQ 号按 qlogo 取头像（`https://q1.qlogo.cn/g?b=qq&nk=<QQ>&s=100`），
  也可以上传本地图片（裁方形、JPEG 0.85 存本机）；不设置则右侧不显示头像。

## 节奏（对照原版）

原版每条消息自带等待时长（v1/v2 叫 `busyWaitTime`，v3 叫 `nextMessageDelayTime`），单位毫秒，中位约 2.4–3.1 秒，另有 2 分钟–4 小时的离线等待。

数据来自三个原版包：`异次元通讯 v1.0`（第一章）、`异次元通讯2 v2.3`（第一/二章 + 两番外）、`异次元通讯3 v3.1`（第一/二/三章 + 两番外），剧情文件做 XOR 0x10 还原后解析。汇总成 `04_资源分析\表\原版节奏_全量.csv`（3,746 条），按章去重后与重置版同章逐字相同的句子共 **2,882 条**（番外一 130 / 番外二 122 / 第一章 590 / 第二章 859 / 第三章 1,181）。

网页版按章加载 `meta.delayMap`（`{章: {文本: 毫秒}}`）：命中就取原值，未命中走拟合模型 `523 + 175 × 字数`；超过 60 秒的「离线等待」不当作打字时长，交给「等待」指令（默认按真实时长）。慢/中/快 = 1.35× / 1× / 0.6×。

**4–6 章**没有原版节奏可用（原版是服务器下发，服务已死），这三章走拟合模型。

## 首页章节分组

- 顺序：第一章 → 番外一 → 第二章 → 番外二 → 第三章 … 第六章；番外作为子条目挂在对应章节卡下方，第一行「第X章番外」、第二行是该章封面上的原版副标题（单行，超出省略）。
- 每张章节卡显示「进度 N%」或「已读完」，进度条按 `st.progress`（本章读过的最远行）计算。
- 点章节 → 先出预览卡（封面 + 该章开头三句原文当钩子 + 天数/行数 + 「与 Miko 一起进入这段冒险」），确认后才播封面并进聊天。
- 前后跳章：往前跳提示「回到《X》（已读 N%）」，往后跳会确认「会跳过前面的剧情」。

## 角色资料页

点聊天里对方的头像进入 `#/user/<角色>`，版式按原版资料页截图复刻：头像 + 昵称（`妹子 · 16岁`）+ 个性签名，
下面两行胶囊——`标签`（描边）/ `兴趣`（紫色实心），再往下是 `日志`。

- 标签、兴趣、签名全部取自原版 APK `com.yinshi.cityline` 的 `resources.arsc` 字符串池：
  标签 `甜食控 / 腿玩年 / 傲娇`，兴趣 `异次元通讯 / JK制服 / 腿控 / 自拍`，
  签名「走在未知的道路上，不许停也不能回头。」；`妹子 · 16岁` 也来自资源串。
- 日志复用已做好的动态数据，**默认只显示最近 3 条**，点「查看全部 34」展开、可再「收起」。
- 每条日志可点赞、评论；未解锁的条目仍按「还没解锁的日志」提示。
- 未认识的角色（问号头像阶段）也能进资料页，只是头像仍是问号；`未知用户` 的条目会落到 Miko 的资料页。

## 头像选择与预览

设置页「角色头像」四行，每行左侧就是当前头像的 34px 圆形预览；点右侧箭头弹出一列（10 张素材 + 「字母」），
选中立刻换图并写进存档，聊天里已经出现的气泡也会同步换。选「字母」时预览显示该角色首字母。

## 进入与切章

- 点章节先弹**章节预览卡**：放大封面 + 本章原文钩子（3 句）+ 天数/行数 + 「与 Miko 一起进入这段冒险」
- 打开即进最近一章（存档优先，否则第一章），先显示 2.4 秒**章节封面**（点一下可跳过）
- 顶部固定「名字 + 状态」：在线是绿点，离线显示「上次在线 N 分钟前 / N 小时 / N 天」
- 左侧气泡不再重复名字（名字只在顶部出现一次）
- 头像三态：`未知=问号` → `知道名字=黑底字母`（`markNamed`）→ `她第一次发图=人物头像`（`checkAvatar`，取该角色第一次「动态带图 / 图鉴由她发出」那一行）；`未知用户` 恒为问号
- 头像揭示点取「最早出现」的一处：角色第一次开口或文本里第一次被点名（Miko 第一章 446「我叫Miko」、Iris 第三章 124、Lily 第四章 1988）；换章/读档时会按进度补算
- 章节列表按剧情顺序（第一→六章，番外最后），每章显示「进度 N% / 已读完」
- 对方说完最后一句后停约 1 秒才淡入选项（`.choices.in`），避免对话突然被选项打断
- 切章提示：往后跳弹确认「会跳过前面的剧情」；往前跳 toast「回到《X》（已读 N%）」，并按该书签续读

## 空间互动（点赞 / 评论 / 回复）

- 角色会按人格评论：Iris 冷静克制（「那不是星星，是城市的灯。」），Lily 寡言（「嗯。」「好看。」），全部 34 条动态都配了台词

### 声音与自动存档（2026-11-06 追加）

- **音乐恢复**：浏览器禁止无交互自动播放，所以进页面后第一次点击/按键时补播 BGM（`armBgm()`）。
- **按键音**：`music/button.ogg`，按钮 / 选项 / 章节卡 / 菜单 / 头像一个列表点击时播放，与「音效 / 语音」开关共用（90ms 节流防叠音）。
- **曲目**：`重置版 · Chill Bells`（`bgm.ogg`，19.9s）与 `2016 原版 · 旧版音乐`（`oldBgm.ogg`，195.7s）可切，存 `settings.bgmTrack`。
- **自动存档**：`settings.autosave`（0 / 30 / 60 / 180 / 300 秒）定时 `save()` 到 localStorage；默认 60 秒。
- **本地备份文件**：Chrome/Edge 的 File System Access API，选一次 `miko-save.json` 后每次自动存档都写盘；句柄存 IndexedDB（`miko-web/h/saveFile`），下次进入提示重新授权。

### 章节解锁 / 聊天记录 / 按键音（2026-11-07）

- **章节解锁**：设置项「解锁全部章节」默认**关闭**。关闭时按 `第一章 → 第一章番外 → 第二章 → 第二章番外 → …` 顺序推进，番外要求对应主线 `done`（读完）；锁定卡片灰底 + 🔒 + 「锁定 · 先读完《X》才能解锁」，点击只提示不进入。
- **每章聊天记录**：`st.chatlog[章]` 按实际播放顺序记录 `{r:行号}` 与 `{c:{i,t:所选文字}}`（上限 6000 条/章），存进存档；重进本章时**整段重放**（含玩家选过的选项），续接点仍是 `marks[章].cur`。
- **按键音**：改到 `click` 事件 + 触摸位移 >8px 判定为滑动（不发声），避免手机上滑屏误响。

### 设置页分组与默认值（2026-11-07）

设置页按用途分成五组：**阅读**（打字速度、等待倍速）→ **声音**（背景音乐 / 曲目 / 音效）→ **进度与存档**（自动存档、本地备份文件、导出导入）→ **解锁与剧透**（红框警示卡）→ **我的形象**（我的头像 + 角色头像）→ 已解锁统计 / 对照表。

- **背景音乐默认开启**；浏览器要求先有一次点击才能出声，所以进游戏后随手点一下即开始播放（设置里有说明）。
- **三项解锁默认关闭 / 默认锁定**：`解锁全部章节`（false）、`自动解锁全部词典图鉴`（false）、`头像随剧情解锁`（true，即锁定开启）。
- 开启前会弹确认：解锁全部章节 → 提示会跳过顺序解锁；自动解锁词典图鉴 → 提示会剧透；关闭「头像随剧情解锁」→ 提示会提前暴露人物身份。取消则开关回退原状。
