# 图片表情

念真单发的图片表情，按她的性格（自嘲、嘴硬、累了就溜）从两个中文表情包里挑的。
只做了尺寸与格式转换（220px 宽 WebP，动图转成 Animated WebP），画面本身没改。

## 来源与许可

| 文件 | 出处 | 许可 |
| --- | --- | --- |
| `bugdone` `nobug` `bugzai` `hairloss` `exception` `tears` `shy` `bald` `nostar` `master` | [getActivity/EmojiPackage](https://github.com/getActivity/EmojiPackage) 的「程序员」目录 | Apache 2.0 |
| `tired` `escape` `silly` `question` `exhausted` `dontplay` `scolded` | [zhaoolee/ChineseBQB](https://github.com/zhaoolee/ChineseBQB) 的「是喵星人啦」 | 仓库未附许可文件 |
| `hairfix` `sideeye` `blowhair` `nolaugh` `smart` `beauty` | 同上，ChineseBQB 的「可爱的女孩纸」 | 仓库未附许可文件 |

ChineseBQB 是一份社区收集的表情包合集，没有写明许可。这里只在个人博客里非商业使用，
并在 [credits.html](../../credits.html) 署名；如果原作者介意，说一声就撤下。

## 用途

### 程序员（自嘲为主）

| id | 画面 | 她什么时候发 |
| --- | --- | --- |
| `bugdone` | 「BUG 修完了吗」 | 被问进度时反问回去 |
| `nobug` | 「保证不生成新Bug」 | 拍胸脯保证，通常是反话 |
| `bugzai` | 「我只是个 BUG 仔」 | 自嘲 |
| `hairloss` | 「头发渐渐消失」 | 熬夜写代码 |
| `exception` | 「向你抛出了一个异常」 | 不想聊了，先撤 |
| `tears` | 「流下了没技术的泪水」 | 写不出来 |
| `shy` | 「技术太渣，完全不敢说话」 | 被大佬问住 |
| `bald` | 「我秃了，也变强了」 | 熬夜之后的自我安慰 |
| `nostar` | 「Star皆空」 | 项目没人 star |
| `master` | 「大佬，教我写代码」 | 真心求教 |

### 猫（情绪出口）

| id | 画面 | 她什么时候发 |
| --- | --- | --- |
| `tired` | 猫瘫着「瘫会儿」 | 累了 |
| `escape` | 猫躲杯子后「逃避现实」 | 想躲开话题 |
| `silly` | 猫「啧，年纪轻轻怎么是个傻子」 | 轻轻损人 |
| `question` | 猫问号 | 没看懂 |
| `exhausted` | 「我累了」猫 | 累到不想动 |
| `dontplay` | 「不！我不跟傻子玩」 | 拒绝搭理 |
| `scolded` | 「你凶我？」猫 | 被凶了的嘴硬 |

### 女孩纸（小动作与嘴硬）

| id | 画面 | 她什么时候发 |
| --- | --- | --- |
| `hairfix` | 理头发（动图） | 不接话的小动作 |
| `sideeye` | 「白了你一眼并不想理你」 | 嘴硬 |
| `blowhair` | 吹刘海儿（动图） | 装没事、臭美 |
| `nolaugh` | 「不许笑」（动图） | 恼羞成怒 |
| `smart` | 「算你识相」（动图） | 嘴上占便宜 |
| `beauty` | 「长得美是我错吗」（动图） | 自恋式回击 |
