# 图片表情

念真单发的图片表情，按她的性格（自嘲、嘴硬、累了就溜）从两个中文表情包里挑的。
只做了尺寸与格式转换（220px 宽 WebP，动图转成 Animated WebP），画面本身没改。

## 来源与许可

| 文件 | 出处 | 许可 |
| --- | --- | --- |
| `bugdone` `nobug` `bugzai` `hairloss` `exception` | [getActivity/EmojiPackage](https://github.com/getActivity/EmojiPackage) 的「程序员」目录 | Apache 2.0 |
| `tired` `escape` `silly` | [zhaoolee/ChineseBQB](https://github.com/zhaoolee/ChineseBQB) 的「是喵星人啦」 | 仓库未附许可文件 |
| `hairfix` `sideeye` | 同上，ChineseBQB 的「可爱的女孩纸」 | 仓库未附许可文件 |

ChineseBQB 是一份社区收集的表情包合集，没有写明许可。这里只在个人博客里非商业使用，
并在 [credits.html](../../credits.html) 署名；如果原作者介意，说一声就撤下。

## 用途

| id | 画面 | 她什么时候发 |
| --- | --- | --- |
| `bugdone` | 「BUG 修完了吗」 | 被问进度时反问回去 |
| `nobug` | 「保证不生成新Bug」 | 拍胸脯保证，通常是反话 |
| `bugzai` | 「我只是个 BUG 仔」 | 自嘲 |
| `hairloss` | 「头发渐渐消失」 | 熬夜写代码 |
| `exception` | 「向你抛出了一个异常」 | 不想聊了，先撤 |
| `tired` | 猫瘫着 | 累了 |
| `escape` | 猫躲在杯子后「逃避现实」 | 想躲开话题 |
| `silly` | 猫：「啧，年纪轻轻怎么是个傻子」 | 轻轻损人 |
| `hairfix` | 女孩理头发（动图） | 不接话的小动作 |
| `sideeye` | 「白了你一眼并不想理你」 | 嘴硬 |
